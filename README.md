# Happy Birthday RB!

An interactive birthday greeting built with React and Vite.

## Run locally

Prerequisite: Node.js 22 or later.

```sh
npm ci --legacy-peer-deps
npm run dev
```

## Deploy to GitHub Pages

The GitHub Actions workflow builds and deploys this app to GitHub Pages whenever
changes are pushed to `main`. In the repository settings, set **Pages → Build
and deployment → Source** to **GitHub Actions**.

After the first successful workflow run, the site will be available at
https://tailwind14u-cell.github.io/hbd1/.
